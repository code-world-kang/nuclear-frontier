# 小康康的物理世界·微信小程序

这是与 GitHub Pages 科研网站共用数据的原生微信小程序。

## 当前功能

- 首页：今日统计、翻译进度、新闻、通知和重点论文。
- 论文：核物理分类、搜索、向下分页浏览。
- 新闻：仅物理领域，分类与详情独立显示。
- 通知：会议、基金、束流申请三类。
- 详情：中文优先、原文对照、收藏、忽略、关键词、页内笔记、Cite 和 Zotero 分类队列。
- 我的：我的论文、我的代码、参考资料。

## 导入与预览

1. 安装微信开发者工具。
2. 选择“导入项目”，目录选择本文件夹。
3. 工程已经绑定个人小程序 AppID：`wxe859c9b09ae5c60d`。
4. 开发阶段如数据请求域名尚未配置，可临时启用“不校验合法域名”。正式发布前必须改用已备案合法域名或云环境。

## 微信云端同步

1. 在微信开发者工具中点击“云开发”并开通环境。
2. 将云环境 ID 填入 `config/cloud.js` 的 `envId`。环境 ID 不是 AppSecret，可以公开；AppSecret 不得写入项目。
3. 在云开发数据库中创建 `research_user_states` 和 `zotero_queue` 两个集合，权限设为“仅管理员可读写”。小程序不直接访问数据库，全部读写由云函数按当前用户 OPENID 隔离。
4. 右键 `cloudfunctions/researchSync`，选择“上传并部署：云端安装依赖”。
5. 在“我的”页面点击“立即同步”验证收藏、笔记、关键词和 Zotero 队列。

本地仍保留离线待同步队列，以便断网时继续记录；云环境恢复后会补传到云端队列。Mac Zotero 助手只读取 `zotero_queue`，任何 Zotero 密钥均不得写入小程序或公开 GitHub。

## 发布前检查

- 在微信公众平台配置数据请求域名，或把公开数据迁移到正式云环境。
- 在真机上验证数据加载、详情、收藏、笔记、网络异常、跨设备同步与 Zotero 回执。
