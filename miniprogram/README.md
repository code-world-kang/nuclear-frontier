# 小康康的物理世界·微信小程序

这是与 GitHub Pages 科研网站共用数据的原生微信小程序。

## 当前功能

- 首页：今日统计、翻译进度、新闻、通知和重点论文。
- 论文：核物理分类、搜索、向下分页浏览。
- 新闻：仅物理领域，分类与详情独立显示。
- 通知：会议、基金、束流申请三类。
- 详情：中文优先、原文对照、收藏、忽略、关键词、页内笔记、Cite 和 Zotero 分类队列。
- 我的：我的论文、我的代码、参考资料。

## 预览

1. 安装微信开发者工具。
2. 选择“导入项目”，目录选择本文件夹。
3. 预览阶段可使用 `touristappid`，并保持“不校验合法域名”。

## 正式发布前必须完成

1. 将 `project.config.json` 的 `appid` 换为正式小程序 AppID。
2. 在微信公众平台配置数据请求域名，或把数据迁移到正式云环境。
3. 接入微信登录与云数据库，用云端队列替换预览版本地状态。
4. 配置 Mac Zotero 同步助手读取云端队列；任何 Zotero 密钥均不得写入小程序或公开 GitHub。
5. 在真机上验证数据加载、详情、收藏、笔记、网络异常与 Zotero 回执。
